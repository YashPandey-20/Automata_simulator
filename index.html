1. Formal 6-Tuple Automata Specifications

Mealy Machine (Output on Transitions)

M1 = (Q, Σ, Δ, δ, λ, q0)

Output function: λ: Q × Σ → Δ
Output length: |Output(w)| = |w| = n

Moore Machine (Output on States)

M2 = (Q', Σ, Δ, δ', λ', q0')

Output function: λ': Q' → Δ
Output length: |Output(w)| = |w| + 1 = n + 1

Conversion Equivalence Theorem:
For any Mealy machine M1, there exists an equivalent Moore machine M2 such that for every input string w ∈ Σ*:
OutputM2(w) = λ'(q0') · OutputM1(w)
Disregarding the initial state output λ'(q0') emitted at step 0, both machines produce bitwise identical response streams for all inputs.

2. Bidirectional Conversion Principles

Mealy → Moore (State Splitting)
  1. Compute incoming outputs: Out(q) = { λ(p, a) | δ(p, a) = q }.
  2. If a state is entered with multiple outputs, split it into (q, b) with λ'(q, b) = b.
  3. Redirect incoming transitions with output b to state (q, b).
  4. Upper bound: |QMoore| ≤ |QMealy| × |Δ|.
  5. Run BFS from q0 to prune unreachable states.
Moore → Mealy (Output Inheritance)
  1. Retain identical state set Q and initial state q0.
  2. State count never increases: |QMealy| = |QMoore|.
  3. Each transition inherits the output of its destination state: λMealy(q, a) = λMoore(δ(q, a)).
  4. Direct 1-step deterministic construction.
