1. Problem Definition & Formal Automata Specifications (1 Mark)

Finite State Machines with outputs are categorized into two foundational formalisms:

  • Mealy Machine: A 6-tuple \(M_1 = (Q, \Sigma, \Delta, \delta, \lambda, q_0)\), where the output function \(\lambda: Q \times \Sigma \to \Delta\) associates output symbols with state transitions.
  • Moore Machine: A 6-tuple \(M_2 = (Q', \Sigma, \Delta, \delta', \lambda', q_0')\), where the output function \(\lambda': Q' \to \Delta\) associates output symbols strictly with states.

Conversion Equivalence Theorem: For any Mealy machine \(M_1\), there exists an equivalent Moore machine \(M_2\) such that for every input string \(w \in \Sigma^*\): \[ \text{Output}_{M_2}(w) = \lambda'(q_0') \cdot \text{Output}_{M_1}(w) \] Conversely, for any Moore machine \(M_2\), there exists an equivalent Mealy machine \(M_1\) such that \(\text{Output}_{M_1}(w)\) matches the reaction output of \(M_2\) for all \(w\) with \(|w| \ge 1\).

4. Selection & Correctness of Algorithms (1 Mark)

Mealy to Moore Algorithm:

  1. Compute incoming output set: \(Out(q) = \{ \lambda(p, a) \mid \delta(p, a) = q \}\) for all \(q \in Q\).
  2. For each \(b \in Out(q)\), create split state \(q_b\) with Moore state output \(\lambda'(q_b) = b\).
  3. Handle initial state: assign \((q_0, \lambda_0)\) where \(\lambda_0\) is designated initial symbol.
  4. Map transitions: \(\delta'((q, b), a) = (\delta(q, a), \lambda(q, a))\).
  5. Execute BFS from \((q_0, \lambda_0)\) to identify and prune unreachable states.

Moore to Mealy Algorithm:

  1. Retain state set \(Q_{Mealy} = Q_{Moore}\) and initial state \(q_0\).
  2. For each transition \(\delta(q, a) = q'\), assign Mealy transition output: \(\lambda_{Mealy}(q, a) = \lambda_{Moore}(q')\).

3. Formal Equivalence Proof Summary

Let \(M_1 = (Q, \Sigma, \Delta, \delta, \lambda, q_0)\) be a Mealy machine and \(M_2 = (Q', \Sigma, \Delta, \delta', \lambda', q_0')\) be the converted Moore machine constructed via the state splitting algorithm.
Basis: For \(|w| = 0\) (empty string \(\epsilon\)): \(\text{Output}_{M_1}(\epsilon) = \epsilon\), while \(\text{Output}_{M_2}(\epsilon) = \lambda'(q_0')\). Thus \(\text{Output}_{M_2}(\epsilon) = \lambda'(q_0') \cdot \text{Output}_{M_1}(\epsilon)\).
Inductive Step: Assume the hypothesis holds for string \(w = a_1 \dots a_k\). For string \(wa = a_1 \dots a_k a_{k+1}\): Let state reached by \(M_1\) after \(w\) be \(q_k\). The \((k+1)\)-th output of \(M_1\) is \(\lambda(q_k, a)\). In \(M_2\), the state reached is \((q_{k+1}, \lambda(q_k, a))\), whose state output is defined as \(\lambda(q_k, a)\). Therefore, the \((k+2)\)-th symbol of \(M_2\) equals the \((k+1)\)-th symbol of \(M_1\). By mathematical induction, output equivalence holds for all strings in \(\Sigma^*\).

Frequently Asked Viva Voce Questions & Model Answers

Q1: What is the fundamental theoretical difference between a Mealy and a Moore machine?

Ans: In a Mealy machine, output is a function of both the current state and the input symbol (\(\lambda: Q \times \Sigma \to \Delta\)). In a Moore machine, output depends solely upon the current state (\(\lambda: Q \to \Delta\)). Consequently, for an input string of length \(n\), a Mealy machine emits \(n\) output symbols, whereas a Moore machine emits \(n+1\) symbols because it emits an initial output upon entering the start state prior to reading any input.

Q2: Why does converting Mealy to Moore sometimes increase the number of states?

Ans: A state \(q\) in a Mealy machine might be entered by multiple transitions producing different output symbols (e.g. entering \(q\) with output 0 on one transition and output 1 on another). Because a Moore machine state can only have one fixed output, \(q\) must split into multiple states \((q, 0)\) and \((q, 1)\). The maximum number of states in the converted Moore machine is \(|Q_{Mealy}| \times |\Delta|\).

Q3: Does converting Moore to Mealy ever change the number of states?

Ans: No. The state set \(Q\), initial state \(q_0\), and transition function \(\delta\) remain completely identical. Each transition \(\delta(q, a) = q'\) simply inherits the output of the target state: \(\lambda_{Mealy}(q, a) = \lambda_{Moore}(q')\).

Q4: How do you formally define equivalence between a Mealy and a Moore machine?

Ans: Two machines \(M_1\) (Mealy) and \(M_2\) (Moore) are equivalent if for all input strings \(w \in \Sigma^*\), \(\text{Output}_{M_2}(w) = \lambda_{M_2}(q_0) \cdot \text{Output}_{M_1}(w)\). That is, when the initial symbol emitted by the Moore machine before reading input is disregarded, both machines produce identical output strings of length \(n\).

Q5: What happens when the initial state \(q_0\) in a Mealy machine has no incoming transitions?

Ans: If \(q_0\) has no incoming transitions, it has no transition output associated with entering it. In the converted Moore machine, \(q_0\) is assigned an arbitrary default output symbol from \(\Delta\) (typically the first symbol in \(\Delta\) or a designated dummy symbol \(\lambda_0\)). Since this symbol is only emitted at step 0 before any input is read, it does not affect reaction equivalence.
